# Model artwork

One illustration per amp/effect model, shown in the amp screen's signal chain, inspector and model browser. `src/core/fxModelInfo.ts` maps each catalog dspId to its file (`<slug>.webp`); `fallback-amp` and `fallback-pedal` stand in for unknown models.

These are original AI-generated illustrations (text prompts only, no photos or Positive Grid artwork as input). They evoke the form factor and colours of the gear that inspired each model but carry no brand names, logos or lettering. They are covered by this repository's licence.

Real gear is only named as text ("Inspired by …"), with the trademark disclaimer from `fxModelInfo.ts`. The optional "Reference photo" link opens a Wikimedia Commons page in the browser; no third-party photos are bundled.

Source images were 512×512 PNG with transparency, converted to WebP (quality 82).
